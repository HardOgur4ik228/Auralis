Quick start

        
      

      

        
Requirements

        
Python 3.9+ and ffmpeg available on PATH.


        
1 · Install dependencies

        
pip install -r requirements.txt


        
2 · Install ffmpeg

        
Windows : https://www.gyan.dev/ffmpeg/builds/
macOS   : brew install ffmpeg
Linux   : sudo apt install ffmpeg


        
3 · Run

        
python app.py

        
Then open http://127.0.0.1:5000 in your browser. You can also run app.py directly from PyCharm.


        
Notes

        
The Whisper model downloads automatically on first use. large-v3 is the most accurate but the heaviest. Set AURALIS_DEVICE=cuda to use a GPU.
